Here is the formatted setup guide:
### Step 1: Update Raspberry Pi Packages
sudo apt update
sudo apt upgrade -y
### Step 2: Install Python and Serial Support
sudo apt install -y python3 python3-pip python3-serial
### Step 3: Install Fingerprint Library
pip3 install adafruit-circuitpython-fingerprint --break-system-packages
(Note: If you are using a virtual environment, activate it first and omit `--break-system-packages`.)*
### Step 4: Enable Raspberry Pi Hardware UART

1. Open the configuration tool:
sudo raspi-config

2. Navigate to:
**Interface Options** $\rightarrow$ **Serial Port**
3. Configure the prompts:
* **Would you like a login shell to be accessible over serial?** $\rightarrow$ **No**
* **Would you like the serial port hardware to be enabled?** $\rightarrow$ **Yes**

4. Exit `raspi-config` and reboot the board:
```bash
sudo reboot

### Step 5: Verify the Serial Device Connection

After the reboot completes, run:

ls -l /dev/serial0

ould point to `ttyAMA0` or `ttyS0`, confirming the hardware UART is active and available for the fingerprint sensor.)*
